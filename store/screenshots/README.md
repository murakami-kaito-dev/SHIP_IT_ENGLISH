# スクリーンショット（App Store 用）

## なぜ自動生成できなかったか
アプリは起動直後（`runApp` の前）に通知許可をリクエストするため、初回起動で
**通知許可ダイアログ**が最初の画面に必ず重なって表示される。`simctl` にはこの
システムダイアログをタップ／事前許可する手段が無い（notifications は privacy
サービス対象外）。そのため“きれいな”スクショをヘッドレスで自動取得できない。
→ 一度だけ手で「許可」を押せば以後は出ないので、下記スクリプトで簡単に撮れる。

## 必要なサイズ（App Store Connect）
| ディスプレイ | 解像度(px) | 代表端末 | 必須? |
|---|---|---|---|
| 6.7インチ | **1290 × 2796** | iPhone 15 Pro Max | **必須**（これ1種でも可） |
| 6.9インチ | 1320 × 2868 | iPhone 16 Pro Max | 6.7の代わりでも可 |
| 6.5インチ | 1242 × 2688 | iPhone 11 Pro Max | 任意（あれば載る） |
| iPad | — | — | **不要**（本アプリはiPhone専用） |

- 各サイズ **3〜10枚**。最初の1〜2枚が検索結果に出るので重要。
- 縦向き（Portrait）。文字を焼き込む場合も実画面が分かる形に。

## 撮り方（一番かんたん）
```bash
cd store/screenshots
./capture.sh                    # 6.7"（iPhone 15 Pro Max）
# 英語版も出す場合はスクリプト内の language_mode を en にして再実行
```
1. スクリプトがシミュレータ起動→ビルド→インストール→**オンボーディングを自動スキップ**→アプリ起動まで実行。
2. 初回だけ通知ダイアログが出るので「許可」を1回タップ。
3. シミュレータで見せたい画面を出し、ターミナルに戻って Enter → `out/01.png` に保存。おすすめ順:
   1. ホーム（今日のセッション＋ストリーク＋週間グラフ）
   2. 学習カード・表面（英語フレーズ）
   3. 学習カード・裏面（和訳＋例文＋評価ボタン。次回間隔「10分/1日」も写る）
   4. カテゴリ一覧（14カテゴリ）
   5. 学習カレンダー（🔥→/history。月別枚数・日別枚数）
   6. カード検索 または 設定
4. `q` + Enter で終了。`out/` に PNG が並ぶ。

## 手動で撮る場合（Xcode/実機でも可）
- シミュレータ: `⌘S`（デスクトップに保存）または `xcrun simctl io booted screenshot x.png`
- 実機: サイドボタン＋音量↑。ただし App Store は上表の解像度が要るので、実機の
  解像度が一致する端末（15/16 Pro Max等）で撮ること。

## 仕上げ（任意・任意ツール）
- 文字キャプション付きの“額縁”スクショにしたい場合は fastlane frameit や
  Figma 等で装飾可能（実画面が分かることが条件）。無くても素の画面で申請できる。
