# アイコン画像の検討用ドラフト（念のため保存）

2026-08-16 のアプリアイコン刷新（滑らかイラスト版ダッキー）にあたって、
Recraft AI で生成・検討した候補画像の保管場所。**アプリからは一切参照されない**。

- `アイコン画像案1〜3.png` … 不採用案（案1=左向き / 案2=目が四角 / 案3=右向き別バリエーション）
- `アイコン画像案4.png` … **採用案**のPNG書き出し（参考。採用の「正」はSVG）

採用した案4の SVG は [assets/icon/app_icon_master.svg](../../assets/icon/app_icon_master.svg)
に保存されており、そこからアイコン（assets/icon/app_icon.png）と
アプリ内マスコット（assets/images/ducky.png）を生成している
（手順はコミット `4061761` 参照）。ここのファイルは「念のため」の控えであり、
削除してもアプリ・ビルドには影響しない。
