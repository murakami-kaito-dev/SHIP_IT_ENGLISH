# 学習データのバックアップと復元

> 学習履歴は端末内の SQLite にのみ保存されており、クラウド同期はしていません。
> 機種変更・アプリ削除で消えるため、書き出し／読み込みの手段を用意しています。
> **課金ユーザーの進捗喪失は解約・返金の最大要因**なので、ストア説明文や
> オンボーディングで案内することを推奨します。

最終更新: 2026-07-20

---

## ユーザー操作（アプリ内）

### バックアップの書き出し

1. 設定タブ → **データ** → **バックアップを書き出す**
2. 共有シートが開くので保存先を選ぶ（「ファイルに保存」/ AirDrop / メール等）
3. `shipit_english_backup_YYYYMMDDTHHMMSS.json` というファイルが保存される

### バックアップからの復元

1. 設定タブ → **データ** → **バックアップから復元**
2. 確認ダイアログで内容を確認（**現在の進捗は上書きされます**）
3. ファイル選択画面で書き出した JSON を選ぶ
4. 復元件数がスナックバーで表示され、ホーム・カテゴリの集計が即座に更新される

## バックアップに含まれるもの／含まれないもの

| 含まれる | 含まれない |
|---------|-----------|
| 学習進捗（`learning_progress` 全行: 記憶度・出題間隔・次回予定日・最終評価） | カード本体（`cards.json` から再生成されるため不要） |
| 日別統計（`daily_stats`: 学習枚数・正答数・学習時間） | サブスクの購読状態（App Store 側で管理。復元は「購入を復元」で行う） |
| ストリーク日数・最終学習日 | 通知の設定 |
| 1日の新規カード枚数・表示言語 | オンボーディング完了フラグ |

### ファイル形式

```json
{
  "format_version": 1,
  "app_version": "1.0.0",
  "exported_at": "2026-07-20T21:00:00.000",
  "learning_progress": [ { "card_id": "cr_001", "ease_factor": 2.5, ... } ],
  "daily_stats": [ { "date": "2026-07-20", "cards_studied": 12, ... } ],
  "preferences": { "streak_count": 5, "last_study_date": "2026-07-20", ... }
}
```

- `format_version` が現在の実装より新しいファイルは読み込みを拒否する
  （将来フォーマットを変えた場合の事故防止）
- 存在しない `card_id` の行が含まれていても、カード側とJOINされる箇所では
  無視されるだけで壊れない

## 開発者向けの補足

### 実装場所

| ファイル | 役割 |
|---------|------|
| `lib/core/services/backup_service.dart` | 書き出し・読み込みの本体 |
| `lib/features/settings/presentation/settings_screen.dart` | 設定画面の導線（`_exportBackup` / `_importBackup`） |

### フォーマットを変更するときの手順

1. `BackupService._formatVersion` をインクリメントする
2. `restore()` に旧バージョンからの変換処理を追加する
   （`format_version` が小さい場合の分岐）
3. 旧フォーマットのファイルで復元できることを実機で確認する

> `format_version` を上げずにフィールドを増やすと、**古いアプリが新しい
> ファイルを読めてしまい**中途半端に復元される。必ずインクリメントすること。

### 追加した依存パッケージ

| パッケージ | 用途 |
|-----------|------|
| `share_plus` | 書き出したファイルを共有シートに渡す |
| `file_picker` | 復元するファイルをユーザーに選ばせる |

いずれも**ネットワーク通信は行わない**ため、App Store の
「データを収集しません」申告に影響はありません。
