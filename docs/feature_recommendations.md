## ⚖️ 要判断（トレードオフがあるため独断で進めない）

### 分析基盤（コンバージョン・解約率の計測）

- **論点**: サブスクを運用するなら「どこで課金され、どこで離脱したか」を測りたい。しかし分析SDK（Firebase等）を入れると、本アプリの強みである **App Store の「データを収集しません」表示が使えなくなる**
- **代替案**: App Store Connect の標準レポート（売上・解約率・トライアル転換率）だけで運用する。個人開発の規模ならこれで足りる可能性が高い
- **推奨**: **まずは標準レポートのみで開始**し、必要になってから検討する
